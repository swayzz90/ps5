# PS5 Monitor

GitHub Pages und GitHub Actions zur Überwachung der zertifiziert generalüberholten PlayStation 5 Slim.

Produkt: https://www.playstation.com/de-de/ps5/certified-refurbished-ps5-slim/product/PSD001-PSDE00233_59-PS5GRADEDCLIZSLE/

Website: https://swayzz90.github.io/ps5/

GitHub Pages aktivieren: Settings > Pages > Source: GitHub Actions. Der Workflow prüft bei seinem Start und anschließend ca. alle 30 Minuten. Für iPhone-Push-Benachrichtigungen in ntfy einen Kanal abonnieren und als GitHub Actions Secret `NTFY_TOPIC` hinterlegen.
